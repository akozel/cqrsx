# Guarantees of the engine: code and tests

Every row is a guarantee of the engine's behaviour: where the code holds it and which tests catch its breach. A change
to that code keeps the guarantee and its tests; a change that renames or moves a test updates this table. The code
refers to a row by its number (`G-NN`). The pages [command path](command-path.html), [read path](read-path.html) and
[task path](task-path.html) explain the guarantees of each path in context.

Paths of the core start at `cqrsx/src` and `cqrsx/tests`, paths of the other crates at the root of the repository,
paths of the demo at `demo/back-end/src` (its integration tests, `tests/…`, at `demo/back-end/`). A file named without
its tests lists all of its tests.
