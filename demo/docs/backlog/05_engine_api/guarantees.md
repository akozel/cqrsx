# Гарантии движка: код → тест → задачи эпика

Раскрытие раздела «Что не меняется» [задачи 01](01_requirements_and_backlog.md). Каждая строка — гарантия, которую
миграция обязана сохранить, где она держится в коде и какой тест её ловит. Столбец «Задачи» называет задачи эпика,
которые трогают этот код: в их разделе «Поведение не меняется: чем доказано» перечислены эти строки. Гарантия без
теста получает тест в [задаче 02](02_guarantees_tests_and_baselines.md), до миграции.

Имена тестов — на 2026-10-27 (HEAD `91dda19`, тесты задачи 02, дерево демо после задачи 03, derive задачи 04, решение команды задачи 05, типизированный id задачи 06, реакции задачи 07, наблюдатель команд задачи 08, обработчики задач задачи 09, витрины задачи 10, модуль и движок в памяти задачи 11, движок на PostgreSQL и MongoDB задачи 12). Файлы демо названы путём от
`back-end/src/` (тесты интеграции — `tests/…` от `back-end/`). Задача, которая переименовывает тест, правит и эту таблицу.
