     гарантий не трогать.

     26, 33 — сверка.

атрибут документации `cqrsx-macros` и одно ужесточение правила архитектуры демо.

- **Документы.**
  - `components.md` и `typical_scenario.md` переехали в корневой `doc/` (`git mv`). 49 живых ссылок в 40 файлах и
    ссылки внутри самих документов пересчитаны. Две ссылки на разделы README ядра, которые с задачи 07 живут в README
    движка, починены.

  - `components.md` получил карту рабочей области, схему зависимостей крейтов и раскладку тестов.
  - Скрипт проверил 71 относительную ссылку в правленых Markdown: битых нет.
- **Документация крейтов — одно правило** (отступление от буквы тикета, решение 08): у `cqrsx`, `cqrsx-engine` и
  `cqrsx-macros` README подключается как документация крейта (`include_str!`), у остальных — один `//!` без README.
  Текст нигде не пишется дважды. Правило записано в CLAUDE.md, корневом README и `components.md`.

  крейты без фич прогоняются по одному.
