# Бэклог

Работа разбита на эпики. Эпик — это каталог со своим `README.md` (цель, таблица задач, порядок, общие правила) и
файлом на каждую задачу. Задачи берём по одной. Ссылка на задачу — `<эпик>/<номер>`, например `02/03`.
