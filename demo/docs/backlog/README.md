# Бэклог

Работа разбита на эпики. Эпик — это каталог со своим `README.md` (цель, таблица задач, порядок, общие правила) и
файлом на каждую задачу. Задачи берём по одной. Ссылка на задачу — `<эпик>/<номер>`, например `02/03`.

| Эпик | Тема | Задач | Статус |
|---|---|---|---|
| [02_postgres_performance](02_postgres_performance/README.md) | Пропускная способность PostgreSQL-хранилища | 22 | 01–04, 06, 08 (08a–08e), 17 сделаны, 05 отклонена по замеру, 14 закрыта тикетом 03/02, 15 отложена; 07, 09–13, 16 перенесены в эпик 04 или заменены его задачами (2026-10-26); здесь же инструменты замера `perf/` |
| [03_durable_projections](03_durable_projections/README.md) | Надёжные проекции: закладка в журнале вместо доставки из команды, replay тем же циклом | 6 | сделан: 01–03 и 04a 2026-10-24, 04 и 05 2026-10-25 |
| [04_operation_costs](04_operation_costs/README.md) | Цена операций после эпика 03: очередь outbox, путь команды, соединения, проекции | 18 | предложено 2026-10-26 по [аудиту производительности](../PERFORMANCE_AUDIT.md); задачи по порядку номеров; 01–04 и 06 сделаны 2026-10-26, 05 отклонена; итог — [results_01_06](04_operation_costs/results_01_06.md) |

Откуда берутся задачи: обсуждения ([`../discussions/`](../discussions/README.md)), аудиты и нагрузочные тесты
([`../../load/`](../../load/README.md)). Новая задача — файл `NN_snake_case.md` в каталоге эпика и строка в его
README. Новый эпик — каталог `NN_snake_case/` и строка в этой таблице.
