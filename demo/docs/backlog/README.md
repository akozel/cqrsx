# Бэклог

Работа разбита на эпики. Эпик — это каталог со своим `README.md` (цель, таблица задач, порядок, общие правила) и
файлом на каждую задачу. Задачи берём по одной. Ссылка на задачу — `<эпик>/<номер>`, например `02/03`.

| Эпик | Тема | Задач | Статус |
|---|---|---|---|
| [01_cqrsx_extractions](01_cqrsx_extractions/README.md) | Перенос кода из demo в `cqrsx` | 10 | 7 сделано, 07, 09, 10 предложены |
| [02_postgres_performance](02_postgres_performance/README.md) | Пропускная способность PostgreSQL-хранилища | 16 | в работе: 01, 02 сделаны |

Откуда берутся задачи: обсуждения ([`../discussions/`](../discussions/README.md)), аудиты и нагрузочные тесты
([`../../load/`](../../load/README.md)). Новая задача — файл `NN_snake_case.md` в каталоге эпика и строка в его
README. Новый эпик — каталог `NN_snake_case/` и строка в этой таблице.
